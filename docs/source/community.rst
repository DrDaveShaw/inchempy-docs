Community
=========

We welcome contributions to INCHEM-Py and look forward to developing the model
further with a community of users. Please get in touch if you need support:

* David Shaw — david.shaw@york.ac.uk
* Nicola Carslaw — nicola.carslaw@york.ac.uk

INCHEM-Py is free software, but as a scientific code we ask that you show
professional courtesy when using it:

#. Since you benefit from work on INCHEM-Py, please submit any improvements
   you make by opening a pull request. Report issues using the `issue tracker
   <https://github.com/DrDaveShaw/INCHEM-Py/issues>`_.
#. If you use INCHEM-Py results in a paper or professional publication, please
   include an appropriate reference. In most cases, if one or more of the
   INCHEM-Py team are involved in preparing results, they should appear as
   co-authors.
#. The INCHEM-Py logo is included with the model and may optionally be used in
   oral or poster presentations.
